I build AI systems that can be trusted in production: ordinary code owns the facts, the model only helps with language, and a human approves everything that leaves the desk.

## Featured project: Faisal Hills AI Lead Desk

An operator-first real-estate lead desk. Buyers' WhatsApp-style questions are qualified, priced strictly from one fingerprinted master inventory, and drafted for human approval. Fact and claim guards trace every number to the approved data; anything untraceable escalates to a person.

[![Faisal Hills AI Lead Desk - operator desk](https://raw.githubusercontent.com/Bunny1239799/faisal-hills-ai-lead-desk/main/docs/screenshots/01-desk.png)](https://github.com/Bunny1239799/faisal-hills-ai-lead-desk)

- 1,189 offline tests passing, 0 failed
- every serving API route covered by a guard (enforced by a test)
- no auto-send by construction: the application drafts, a human sends
- Python and SQLite core, FastAPI console, no build step, no paid API
