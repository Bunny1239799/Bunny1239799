## Featured project

### Faisal Hills AI Lead Desk

An operator-first real-estate lead desk. Buyers' WhatsApp-style questions are qualified, priced **only** from a fingerprinted master inventory, and every reply is drafted for **human approval**. Fact and claim guards trace every number to approved data; anything untraceable escalates to a person. There is no send capability in the code.

[![Faisal Hills AI Lead Desk - operator desk](https://raw.githubusercontent.com/Bunny1239799/faisal-hills-ai-lead-desk/main/docs/screenshots/01-desk.png)](https://github.com/Bunny1239799/faisal-hills-ai-lead-desk)

- **1,189 offline tests passing, 0 failed** - and a test that walks every API route to prove each serving surface is guard-covered
- Approved-master-only pricing, with the served fingerprint visible on every page
- Versioned inventory workspace, exact transcript replay, live system-status view
- Python and SQLite core, FastAPI console, no build step, no paid API
